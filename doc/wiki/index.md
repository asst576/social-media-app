# Commonplace Wiki

Commonplace is a server-rendered Django social application with regular members, staff-provisioned campaign managers, and simulated sponsored campaigns.

- [Architecture](architecture.md): Django apps, data relationships, feeds, reposts, and ad delivery.
- [Development](development.md): local setup, CodeRange configuration, account provisioning, and validation commands.
- [Advertising](advertising.md): campaign review, simulated purchases, and sponsored-feed eligibility.
- [Footguns](footguns/index.md): CodeRange prefix/CSRF handling and repost/campaign behavior to preserve.

These pages describe implemented behavior only. Deferred features are listed in the repository `README.md`.
